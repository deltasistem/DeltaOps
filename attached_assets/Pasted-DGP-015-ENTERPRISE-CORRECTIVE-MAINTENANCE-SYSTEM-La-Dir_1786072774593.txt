DGP-015 · ENTERPRISE CORRECTIVE MAINTENANCE SYSTEM

La Dirección del Programa autoriza el inicio de la fase DGP-015 — Enterprise Corrective Maintenance System.

Esta fase deberá construirse siguiendo exactamente las mismas reglas arquitectónicas de todo el programa.

Restricciones generales
No modificar ningún paquete del corpus congelado.
Toda nueva funcionalidad deberá implementarse por composición utilizando únicamente contratos públicos.
Mantener Clean Architecture, DDD, CQRS, Event Driven, Offline First, Configuration First, Multiempresa y RLS.
No introducir nuevas dependencias de UI distintas al Design System.
No introducir nuevos motores si ya existe uno reutilizable.
Objetivo

Construir el Sistema Empresarial de Mantenimiento Correctivo como un nuevo módulo empresarial:

@workspace/module-correctivo

que reutilice por composición:

Module Activos
Module Órdenes
Module Inventario
Module Abastecimiento
Workflow Engine
Dynamic Forms
Business Foundation
Shared Platform
Design System

sin modificar ninguno de ellos.
