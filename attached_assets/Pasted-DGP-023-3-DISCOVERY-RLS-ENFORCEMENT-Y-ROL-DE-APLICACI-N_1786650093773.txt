DGP-023.3 — DISCOVERY: RLS ENFORCEMENT Y ROL DE APLICACIÓN POSTGRESQL

Programa DeltaOps

ESTADO DEL PROGRAMA

DGP-023 Discovery identificó H-02:

La aplicación conecta actualmente a PostgreSQL mediante un usuario con privilegios de superusuario / rol que posee bypass de RLS, por lo que PostgreSQL no aplica realmente las políticas RLS durante el runtime.

DGP-023.2 retiró definitivamente SGMA.
DeltaOps es ahora el único producto operativo.

OBJETIVO

Realizar un Discovery técnico completo para diseñar la transición desde la conexión actual de PostgreSQL hacia un rol de aplicación que NO pueda evadir RLS.

Esta fase es EXCLUSIVAMENTE DISCOVERY.
